# Railway Reservation System

A beginner-friendly console-based Railway Reservation System developed using Core Java.

## Features

* View all available trains
* Search trains by source and destination
* Book railway tickets
* Generate unique PNR numbers
* View ticket details using PNR
* Cancel tickets
* Check seat availability
* View all bookings

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* ArrayList
* HashMap
* Scanner
* Exception Handling
* Java Date and Time API

## How to Run

### Prerequisites

Install the Java Development Kit (JDK).

### Compile

```bash
javac Main.java Train.java Passenger.java Ticket.java ReservationSystem.java
```

### Run

```bash
java Main
```

## Note

This is an educational console application. Booking data is stored in memory and resets when the program exits.
